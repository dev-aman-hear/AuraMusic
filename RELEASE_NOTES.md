# AuraMusic 3.2.0 (Glass Edition)

Release Date: October 2026

## ✨ What's New in 3.2.0

* **Ultra-HD Online Media Artwork Engine**:
  * **YouTube Music Master Art**: Automatically upgrades compressed mobile thumbnails (`=w60`, `=w120`) to studio-grade `1080x1080` uncompressed covers directly from Google content servers.
  * **YouTube Video Thumbnail Clarity**: Strips mobile compression parameters (`?sqp=...`) and elevates low-res previews to clean, full-definition `hqdefault` artwork.
  * **JioSaavn Studio Covers**: Delivers `500x500` uncompressed Akamai CDN album covers with secure HTTPS protocol enforcement across all search tracks, curated playlists, and player screens.
* **Universal Frosted Glass UI**:
  * System-wide frosted glass surface treatment with specular highlight borders and subtle blur overlays across the bottom navigation bar, mini player, category cards, library sheets, song rows, dialogs, and player controls.
* **Dribbble-Inspired Dynamic Search & Discovery Tab**:
  * Fluid glowing mesh category cards, adaptive Light & Dark mode support, instantaneous keyboard dismissal on category selection, and dynamic gradient highlights.
* **Artist Cloud & YouTube Artist Discovery**:
  * Interactive artist chips and rich artist discovery sheets with high-resolution profile imagery and instant track exploration.
* **Unified Home Experience**:
  * Replaced temporary navigation with a unified Home experience featuring proportional greeting headers and daily curated discoveries.

# AuraMusic 3.1.0 (Glass Edition)

Release Date: August 2026

## ✨ New Features

* **ColorOS Live Lyrics Bridge**: Real-time status bar / capsule live lyrics support for ColorOS & compatible Android devices.
* **Artists Section**: Dedicated Artists tab with circular artist avatar pictures and artist track lists.
* **Time-of-Day Greetings**: Dynamic greeting header on Home screen (Good Morning / Afternoon / Evening).
* **Grid Customization**: Adjustable playlist grid column count in settings.

## 🚀 Improvements

* Enhanced Glassmorphic UI finish across player and settings.
* Improved audio focus, notification status management, and background service stability.
* Refined playback queue handling and track metadata resolution.

## 🐛 Bug Fixes

* Fixed artwork loading and palette extraction edge cases.
* Resolved playback state synchronization glitches.
* Overall performance optimizations and memory improvements.
